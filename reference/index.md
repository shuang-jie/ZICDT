# Package index

## Structure learning

Learn a directed tree/forest over compositional nodes.

- [`zicdt_cv()`](https://shuang-jie.github.io/ZICDT/reference/zicdt_cv.md)
  : Select the penalty by cross-validation and fit the final structure
- [`zicdt_fit()`](https://shuang-jie.github.io/ZICDT/reference/zicdt_fit.md)
  : Fit a directed tree/forest at a fixed penalty
- [`zicdt_edges()`](https://shuang-jie.github.io/ZICDT/reference/zicdt_edges.md)
  : Extract the learned edges as a data frame

## Simulation

Generate zero-inflated compositional data on a known tree.

- [`zicdt_simulate()`](https://shuang-jie.github.io/ZICDT/reference/zicdt_simulate.md)
  : Simulate zero-inflated compositional data on a directed tree
